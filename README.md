# Mobile Prototype Stage v2

`Mobile Prototype Stage v2` создаёт или адаптирует кликабельные мобильные прототипы. На телефоне пользователь видит интерфейс приложения, на компьютере — сцену с настройками сценариев и режим презентации с мокапом устройства. Внутри мокапа работает сам прототип: можно нажимать кнопки, вводить данные и проходить пользовательский сценарий.

## Как подготовить проект

1. Откройте в Codex проект, в котором нужно собрать или доработать прототип.
2. Опишите сервис, основной пользовательский сценарий и состояния, которые нужно показать: например, загрузку, успешную оплату или ошибку.
3. Приложите доступные макеты, референсы и материалы продукта. Если интерфейс уже реализован, укажите нужные экраны.
4. Укажите платформу и размер сцены, если они отличаются от начальных настроек. По умолчанию используются iOS, светлая тема и размер 393 × 852 px.

Запустите навык:

```text
Используй $mobile-prototype-stage-v2 для этого проекта.
Собери кликабельный прототип оформления заказа с состояниями:
корзина, оплата, успех и ошибка.
Добавь сцену и режим презентации.
```

Для существующего интерфейса:

```text
Используй $mobile-prototype-stage-v2.
Добавь сцену и презентацию к существующему прототипу,
сохрани его пользовательские сценарии и состояние экранов.
```

## Что будет на выходе

На мобильном устройстве прототип занимает весь экран. Настройки сцены, мокап и оформление презентации скрыты.

На компьютере доступны три режима:

- **Сцена** — мобильный интерфейс без корпуса телефона, переключатели сценариев, iOS/Android, светлой/тёмной темы, размера и скругления сцены.
- **Презентация** — живой интерфейс внутри мокапа, фон и панель настройки композиции справа.
- **Превью** — презентация со скрытыми настройками. Выйти можно кнопкой «Выйти из превью» или клавишей Esc.

Переходы между режимами сохраняют состояние прототипа, прокрутку и выбранные настройки. Варианты сценариев хранятся отдельно от компонентов интерфейса.

## Сцена и системные панели

Размер сцены задаётся в пикселях. Начальные значения — 393 × 852 px; интерфейс сохраняет этот логический размер и при необходимости пропорционально уменьшается для размещения на экране компьютера.

Скругление по умолчанию — 60 px для iOS и 50 px для Android. Его можно менять от 0 до 120 px как на сцене, так и в презентации. Настройки синхронизированы, а значения для платформ сохраняются отдельно. Скругляется только поверхность интерфейса: геометрия мокапа не меняется.

Системные панели используют SVG из комплекта скила. Они поддерживают iOS/Android и светлую/тёмную тему. Для Android по умолчанию используется жестовая навигация; кнопочная добавляется по отдельному запросу.

## Режим презентации

В комплекте есть мокапы iPhone и Android · Pixel 10 Pro, а также вариант «Без корпуса». При переходе со сцены устройство выбирается автоматически по текущей платформе. Выбор другого устройства в презентации переключает системные панели интерфейса.

Для iPhone доступны графитовый корпус по умолчанию и серебристый. Android использует собственный тёмный корпус.

В панели можно настроить:

- масштаб телефона — от 40 до 100%, по умолчанию 90%;
- положение по горизонтали и вертикали;
- формат кадра — по окну, 16:9, 4:3, 1:1 или 9:16;
- скругление сцены;
- фон и отображение курсора.

Мокап остаётся прямым: поворота, наклона и дополнительной объёмной боковой грани нет.

## Фон и изображения

Доступны цвет, двухцветный градиент и изображение.

Для начального градиента навык выбирает два цвета из самого макета: **либо два тёмных, либо два светлых**. Он не смешивает светлый цвет с тёмным и не осветляет тёмную палитру автоматически. Цвета панели настроек и корпуса телефона не используются как палитра продукта. Оба цвета и угол градиента можно изменить вручную.

В режиме «Изображение» по умолчанию выбран встроенный тёмный фон с рукой. Над кнопкой загрузки расположена небольшая галерея миниатюр. Сейчас в ней одно изображение; новые фоны добавляются в массив пресетов. Можно загрузить и свой файл.

Настройки изображения находятся в свёрнутом блоке **«Настроить изображение»**:

- заполнить кадр или вписать изображение;
- масштаб — от 25 до 300%, по умолчанию 100%;
- смещение по двум осям;
- сброс масштаба и положения.

Эти настройки меняют только фон. Выбор цвета фона в режиме изображения скрыт. Файлы мокапов и стандартного фона входят в скил и не требуют загрузки из сети при запуске шаблона.

## Курсор для демонстрации

Кнопка **«Скрывать курсор»** находится только в настройках презентации. При включении внутри интерфейса обычный указатель заменяется белой точкой размером 6 px. При нажатии кнопки появляются три расходящихся кольца.

Указатель-рука над кнопками также скрывается. За пределами интерфейса остаётся обычный курсор. На мобильных устройствах точка и кольца не отображаются; анимация учитывает настройку уменьшения движения.

## Готовый шаблон и настройки

Скил находится в [`skills/mobile-prototype-stage-v2/`](skills/mobile-prototype-stage-v2/). Внутри него:

- [`SKILL.md`](skills/mobile-prototype-stage-v2/SKILL.md) — правила сборки и проверки прототипа.
- [`assets/starter/index.html`](skills/mobile-prototype-stage-v2/assets/starter/index.html) — самостоятельный рабочий пример сцены и презентации.
- [`assets/starter/defaults.json`](skills/mobile-prototype-stage-v2/assets/starter/defaults.json) — начальные настройки и список фоновых пресетов.
- `assets/system-bars/` и `assets/controls/` — системные панели и иконки управления.
- `assets/presentation/` — мокапы, шрифт, фон и сведения об источниках материалов.

Продуктовый экран в шаблоне — пример. При работе над другим сервисом навык заменяет его содержимое и сценарии, сохраняя поведение оболочки. Начальные цвета градиента также подбираются заново под продукт.

При переносе шаблона нужно сохранить весь каталог `assets/` и относительные пути. Если меняются значения по умолчанию, обновляются и HTML, и `defaults.json`. Файл настроек описывает начальные значения; сохранение пользовательских изменений между перезагрузками браузера не реализовано.

## Как установить и открыть пример

Скопируйте папку `skills/mobile-prototype-stage-v2` в каталог навыков Codex:

```text
~/.codex/skills/mobile-prototype-stage-v2/
```

Для запуска встроенного примера нужен Python 3. Из корня этого репозитория выполните:

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory skills/mobile-prototype-stage-v2
```

Откройте [локальный пример](http://127.0.0.1:8765/assets/starter/). Для сцены и панели презентации нужна ширина окна от 768 px. При меньшей ширине показывается только мобильный интерфейс. Если порт занят, выберите другой номер и замените его в адресе.

## Проверка результата

После сборки навык проверяет мобильную и настольную версии, переключение сценариев и платформ, системные панели, соответствие мокапа и размеры сцены.

Отдельно проверяются вход и выход из превью без сброса состояния, независимое скругление сцены, работа фоновых изображений, сохранение ручных настроек и скрытие курсора над интерактивными элементами. Недоступные проверки и оставшиеся ограничения указываются в отчёте.
